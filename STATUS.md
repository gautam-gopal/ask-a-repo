## What works

- Live at https://ask-a-repo.onrender.com (Render free, auto-deploy from `main`): authentication, GitHub integration, chunker (50-line windows / 10-line overlap / 1500-character maximum), Cloudflare Workers AI embeddings (768 dimensions), MongoDB Atlas Vector Search (`chunks_vector`), ingestion, retrieval, Groq answers (gpt-oss-120b with gpt-oss-20b fallback), SSE streaming, message persistence, retrieval evaluation, rate limits, daily budgets, signup cap, CSP, redacted logs, CI and read-only demo mode.

- Phase 14A: design tokens in `client/src/styles/tokens.css`, conventions in `client/DESIGN.md`, redesigned application header and shell, polished login and repositories pages, responsive layouts, accessible form validation and native progress bars. Decisions D-106 to D-110.

- Phase 14B: Markdown answers rendered through `client/src/components/AnswerMarkdown.jsx` using `react-markdown@10.1.0` and `remark-gfm@4.0.1`, pinned exactly.
  - Bold, italic, headings, lists, task lists, tables and strikethrough render as Markdown.
  - Fenced code blocks show a language label and Copy button.
  - Tables scroll inside their own container.
  - Raw HTML is not rendered as active HTML.
  - Images do not load; only their alternative text is displayed.
  - Only HTTPS GitHub links become clickable anchors. Other links remain text.
  - Citation chips are generated by `client/src/remarkCitations.js` from validated source numbers.
  - Both `[n]` / `【n】` and annotated forms such as `[n†lines=START-END]` are supported.
  - Server-side citation extraction validates numbers against the excerpts supplied to the model and removes model-generated line annotations.
  - Citation chips navigate to the matching source entry and visibly highlight it. Repeated clicks can trigger the highlight again.
  - Decisions D-111 to D-116.

- Phase 14B manual functional checks: Markdown formatting, code Copy button, 360px layout, inline citation rendering, citation navigation and source highlighting verified.

- Automated tests: 647 tests passed across 28 test files, including Markdown security, formatting and citation tests.

- Latest production client build: successful.
  - JavaScript: 145.70 kB gzip.
  - CSS: 4.28 kB gzip.
  - Before Phase 14B: JavaScript 92.52 kB gzip; CSS 3.72 kB gzip.

- Dependency audits: server and client reported zero vulnerabilities during the latest build.

- Production-mode server startup verified with `NODE_ENV=production`.

- Production indexing skips test files by default (D-087). `SEARCH_MIN_SCORE=0.795` remains provisional (D-089).

- Retrieval evaluation (30 on-topic questions, 8 off-topic questions, 2 repositories): baseline Hit@5 80.0%; B2 Hit@5 86.7%. Test-targeted questions: 0/4 with test exclusion and 4/4 without.

- `DECISIONS.md` contains D-001 through D-116. `BUGS.md` contains B-001.

## What is broken or unverified

- Final browser-console verification of CSP violations in production mode is pending. The server has started with `NODE_ENV=production`; confirm the browser Console has no CSP violations involving scripts, styles, fonts or external resources.
- The manual browser-based prompt-injection test for Markdown output has not been recorded. Automated security tests in `server/test/markdown.test.js` cover hostile HTML, unsafe links and image-loading attempts.
- Phase 14C remains: redesign the chat page layout, improve the sources panel and composer, add citation hover highlighting, and remove remaining legacy chat styling.
- Demo mode: read-only demo account and two seeded repositories are deployed and verified. Demo messages expire after 24 hours. Demo visitors share an IP-based rate-limit bucket; follow-up questions do not receive conversation history.
- `DAILY_LLM_REQUEST_BUDGET=500` remains a placeholder pending verification against the Groq account quota.
- Budget calculations are estimates. In-memory rate limiters reset on restart and are not shared across multiple server instances.
- Existing non-demo repositories indexed before test-file exclusion may still contain test chunks.
- Four B2 retrieval failures remain. The evaluation dataset is small and the threshold was tuned using the same dataset.
- Phase 11 hybrid search remains deferred.
- Docker image and linting remain deferred (D-098).
